# Xaero Tactical Map

**基于 Xaero 地图的战术感知模组 · Minecraft 1.20.1 Forge**

ATAK 风格的路点战术面板、双制式方位读数、军事符号标注与小队协同

</div>

---

## 功能特性

### 战术 HUD（游戏内常显）
- 屏幕角落常显最近路点列表：距离 / 罗盘方位 / 八向方位词，每秒刷新 10 次
- **双制式方位读数并存**：罗盘制（北 = 0°）与朝向制（南 = 0°，即 F3 Facing 读数）并排显示，无需切换

### 大地图战术面板（M 打开地图）
- 悬停路点弹出战术面板：精确到 0.1 的距离与双方位读数
- 玩家到目标的战术方位虚线，中点标注距离与双读数
- 悬停面板数据随玩家移动实时重算

### 战术标注（v4.0 新增）
- 地图左侧工具栏：点 / 路线 / 多边形 / 圆 四种标注
- 军事符号面板：我方蓝色 12 种（小队色）+ 敌方红色 8 种（敌情 / 可疑 / 伏击 / 狙击 / 打击目标 / 集结点 / 基地 / 星形）
- 多边形防自交（Z 字序自动修正），四边形直接四角落点
- 标注名称与方位读数随缩放淡入淡出，悬停强制显示

### 小队系统与会话同步（J 打开面板）
- 创建 / 加入小队，每队固定颜色，敌情永远红色
- 基友服局域网 / 服务器同步：Forge 网络包，未装模组的服务器可正常进入（同步自动休眠）
- 标注按维度隔离，导出 / 导入 JSON

## 安装

1. 安装 Minecraft 1.20.1 + Forge 47.4.22+
2. 安装 Xaero's Minimap（26.5.0+）与 Xaero's World Map（1.46.0+）
3. 把模组 jar 放入 `mods` 文件夹
4. 进游戏：M 打开地图看工具栏，J 打开小队面板

## 从源码构建

```bash
./gradlew build
# 产物位于 build/libs/
```

## 技术说明

- 罗盘制方位：北 = 0°、东 = 90°、南 = 180°、西 = 270°
- 朝向制方位（F3 yaw）：南 = 0°、西 = 90°、北 = 180°、东 = -90°，公式 `yaw = atan2(-Δx, Δz)`
- 两者换算：罗盘 =（朝向 + 180）取模 360
- 网络协议向后兼容，新旧版本客户端可互通
